# ميقاتي — تطبيق مواقيت الصلاة

تطبيق PWA عربي للهواتف، يحسب مواقيت الصلاة على جهاز المستخدم اعتمادًا على الموقع الفعلي أو مدينة يختارها. يتضمن عدًّا تنازليًا للصلاة التالية، اتجاه القبلة، أصوات أذان مرخّصة، ونسخة تعمل دون اتصال بعد اكتمال أول تحميل.

## ما يعمل الآن

- تحديد الموقع بإذن المستخدم مع حفظه محليًا، أو اختيار مدينة سعودية، أو إدخال إحداثيات.
- حساب الفجر والشروق والظهر والعصر والمغرب والعشاء محليًا باستخدام مكتبة [Adhan JS](https://github.com/batoulapps/adhan-js). طريقة أم القرى افتراضيًا، مع خيارات رابطة العالم الإسلامي والهيئة المصرية، وحساب عصر الجمهور/الحنفية وتصحيح ±٣٠ دقيقة.
- إضافة ٣٠ دقيقة للعشاء في رمضان عند استخدام طريقة أم القرى، حسب توصية المكتبة. المواقيت حسابات فلكية، وقد تختلف عن تقويم المسجد أو الجهة الرسمية؛ يمكن تعديلها من الإعدادات.
- تشغيل الأذان العادي أو أذان الفجر بالضغط على زر التشغيل، ومحاولة تشغيل الصوت وإظهار تنبيه عند دخول الوقت **أثناء فتح الصفحة وظهورها على الشاشة** إذا سمح المتصفح.
- تصميم عربي RTL مهيأ لشاشة iPhone، وملفات Manifest وService Worker ونسخة `docs/` الجاهزة لـGitHub Pages.

**حدود مهمة:** لا تحتوي هذه النسخة على خادم Web Push. عند إغلاق التطبيق أو قفل الشاشة لا تُجدول تنبيهات موثوقة، ولا يمكن ضمان تشغيل الأذان الصوتي كاملًا في الخلفية على iPhone. إذا كان التنبيه عند الإغلاق مطلوبًا، يلزم خادم Push واشتراك المستخدم. إذا كان تشغيل الأذان كاملًا رغم الإغلاق شرطًا، يُفضّل تطبيق أصلي أو غلاف أصلي بعد تقييم قيود iOS. لا تعتمد على النسخة الحالية باعتبارها منبهًا وحيدًا للصلاة.

## التشغيل والتطوير

```bash
npm ci
npm run icons
npm test
npm run dev
```

افتح العنوان الذي يعرضه Vite (`/prayer-time/`). يتطلب تحديد الموقع HTTPS أو `localhost`؛ قد لا تعمل الميزة إذا فتحت `index.html` مباشرة بوصفه ملفًا محليًا.

## بناء ونشر GitHub Pages

```bash
npm run build
```

يبني هذا الأمر النسخة النهائية في مجلد `docs/`. بعد رفع الملفات إلى `main`، افتح إعدادات مستودع GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**، ثم اختر `main` ومجلد `/docs` واحفظ. رابط الموقع المتوقع بعد تفعيل Pages: `https://ibr7h.github.io/prayer-time/`. لا يُفعّل Pages بمجرد رفع الملفات؛ تأكد من ظهور رابط الموقع في Settings قبل مشاركة الرابط. على iPhone افتح الموقع عبر Safari ثم **مشاركة → إضافة إلى الشاشة الرئيسية**.

إعادة البناء تُحدّث الملفات داخل `docs/`؛ ينبغي ضم تغييرات المصدر والنسخة المبنية معًا عند نشر إصدار جديد. يعتمد وضع عدم الاتصال على اكتمال تثبيت الملفات في Service Worker بعد أول زيارة ناجحة.

## الخصوصية والتوقيت

لا يحتوي المشروع على خادم لتلقي المواقع: تبقى الإحداثيات والإعدادات في تخزين المتصفح، ويجري الحساب محليًا. قد تستخدم خدمة تحديد الموقع في الجهاز خدمات النظام الخاصة بها. تستخدم مدن السعودية توقيت `Asia/Riyadh`، بينما يعتمد تحديد GPS والإحداثيات اليدوية على التوقيت المضبوط في الجهاز؛ تحقق منه عند السفر أو إدخال إحداثيات خارج منطقتك. عند فتح التطبيق، يعاد طلب موقع GPS فقط إذا كان الإذن ممنوحًا مسبقًا.

## حقوق الصوت

مصدر كل تسجيل وترخيصه في [توثيق الأصوات](public/audio/ATTRIBUTION.md). لا تشمل تراخيص الصوت أي ترخيص عام لشفرة التطبيق. لم تُدرج تسجيلات صفحة Doaa-Mp3 لعدم التحقق من إذن إعادة نشرها في مستودع عام.
